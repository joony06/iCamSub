# iCamSub

iCampus Subtitle — 성균관대 iCampus(Canvas) 강의 영상 위에 자막을 띄우는 크롬 확장프로그램.

## 아이콘 교체
`icons/` 폴더의 `icon16.png`, `icon32.png`, `icon48.png`, `icon128.png`를 같은 이름으로 덮어쓴 뒤 확장 새로고침.

## 설치
1. `chrome://extensions` → 우측 상단 **개발자 모드** 켜기
2. **압축해제된 확장 프로그램 로드** → 이 폴더 선택

저장소: https://github.com/joony06/iCamSub

## 쓰는 법
- 강의 영상이 뜬 상태에서 SRT 파일을 플레이어 위로 끌어놓거나, 확장 팝업에서 파일 선택
- 공유 자막이 올라와 있는 강의는 열기만 하면 자동으로 표시됨
- 싱크 조절: 팝업 버튼 또는 플레이어 클릭 후 `[` `]` (0.5초씩)
- `Shift+S`: 자막 켜기/끄기

## 공유 자막 올리기 (관리자용)
0. 팝업 상단의 **iCamSub** 제목을 빠르게 5번 클릭해 관리자 모드 켜기 (다시 5번 누르면 꺼짐)
1. 강의 페이지에서 SRT를 불러온 뒤 팝업의 **공유용 파일 내보내기** 클릭
2. 받은 `<해시>.json` 파일을 이 저장소의 `subs/` 폴더에 커밋

파일 이름은 콘텐츠 ID의 해시이고 내용은 콘텐츠 ID로 만든 키로 AES-GCM 암호화되어 있어서,
강의 페이지에 들어갈 수 없는 사람은 저장소를 봐도 어떤 강의인지, 무슨 내용인지 알 수 없습니다.
